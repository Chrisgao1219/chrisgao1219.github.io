使用场景

独立站运营 — 竞品分析 · KOL 寻找 · 价格监控 · 数据采集

🔍 竞品分析

打开 myshop.com 和 competitor.com，对比首页商品布局、定价策略、促销方式，给我分析报告。

🎯 KOL / 红人寻找

在 YouTube 搜索 espresso machine review，提取 Top 20 视频的频道名、播放量、链接，整理成红人候选名单。

📊 价格监控

每天早上 9 点打开 competitor.com/product-a，提取价格。如果比昨天降价超过 10%，立即通知我。

🧩 更多独立站场景

📦 竞品新品监控

打开竞品 New Arrivals 页，提取新品列表，告诉我哪些是新的、和我的产品线有什么差异。

⭐ 评论分析

打开商品评论页，找出所有差评，汇总用户最不满意的 5 个问题，生成改进建议。

🏷 SEO 关键词研究

打开 Google 搜索品类关键词，提取相关搜索和 People Also Ask，整理关键词列表。

📸 社媒素材收集

打开 Instagram 竞品主页，截图最近 10 条帖子，分析视觉风格并给我创意建议。

📋 批量填表

打开 Shopify 后台上新页面，把这份产品信息填进去：标题 xxx、价格 xxx、描述 xxx。

🛒 购物流程测试

打开 myshop.com，完成加购到结账全流程，检查是否有页面错误或流程卡顿。

📢 广告投放调研

打开 Facebook Ad Library，搜索竞品品牌名，截图最近投放的 10 条广告，分析创意方向和文案策略。

🏭 供应链比价

打开 Alibaba 搜索产品关键词，提取前 20 个供应商的报价、起订量、发货时间，整理比价表。

🎫 竞品优惠策略

打开竞品网站，加入购物车但不付款。第二天检查是否收到弃购挽回邮件或弹窗优惠券。

📧 邮件营销分析

用 3 个不同邮箱注册竞品 Newsletter。一周后打开收件箱，分析欢迎邮件序列、促销节奏、模板风格。

📦 库存状态监控

每天打开竞品热销商品页面，检查是否显示售罄或库存紧张，记录补货时间规律。

🔗 外链和合作追踪

Google 搜索竞品品牌名，翻到第 5 页，找出哪些博客、媒体、论坛提到了他们，整理成外联名单。

💡 以上全部指令都是对 Claude Code 说的自然语言。
不需要写代码，不需要记命令。AI 自动操作浏览器完成。

快速上手

需要电脑上装了 Node.js（版本 18 以上）

  1. 1 下载代码：git clone https://github.com/Chrisgao1219/chrisgao-chrome.git
  2. 2 装好命令行工具：cd chrisgao-cli cd chrisgao-cli && npm linkamp;cd chrisgao-cli && npm linkamp; npm link
  3. 3 装好 AI 连接器：cd chrisgao-mcp cd chrisgao-mcp && npm installamp;cd chrisgao-mcp && npm installamp; npm install
  4. 4 装 Chrome 插件：打开 chrome://extensions → 打开右上角开发者模式 → 点加载已解压的扩展程序 → 选 chrisgao-chrome-extension 文件夹
  5. 5 启动：chrisgao daemon start
